# Мебельщик — мобильное приложение

## Что уже работает
- Заказы: добавление, редактирование, удаление и поиск.
- Автоматический расчёт рабочих часов и дохода в час.
- Раздельные часы для каждой субботы и воскресенья.
- Аналитика по месяцам и годам.
- Средний доход за рабочий день только по уже наступившим рабочим дням.
- Офлайн-работа и установка на главный экран.
- Резервная копия JSON и экспорт заказов CSV.
- Исходные данные перенесены из Excel.

## Как запустить
PWA нужно открыть через HTTPS или локальный веб-сервер.

### Самый простой способ публикации
1. Распакуйте архив.
2. Загрузите всю папку на Netlify Drop, Vercel или GitHub Pages.
3. Откройте полученную ссылку на телефоне.
4. Android: меню браузера → «Установить приложение».
5. iPhone: «Поделиться» → «На экран Домой».

### Проверка на компьютере
В папке приложения:
```bash
python -m http.server 8080
```
Затем откройте `http://localhost:8080`.

## Хранение данных
Данные хранятся в localStorage браузера на конкретном устройстве. Регулярно используйте
«Настройки → Скачать резервную копию».
